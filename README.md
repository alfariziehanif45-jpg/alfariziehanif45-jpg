# 💫 About Me:
Halo, saya Hanif. Saya merupakan mahasiswa D3 Manajemen Informatika di Universitas Sriwijaya yang memiliki ketertarikan besar terhadap teknologi, pengembangan website, dan aplikasi mobile.<br><br>Saya senang mempelajari bagaimana sebuah website dan aplikasi dapat dibuat menjadi lebih menarik, interaktif, dan mudah digunakan. Saya sudah membuat beberapa project, seperti RPG Gacha (game berbasis web), Campus Lost (aplikasi mobile untuk melaporkan barang hilang di kampus), dan Wisata Negara ASEAN (website wisata dengan peta interaktif). Untuk mengerjakannya, saya memakai HTML, CSS, JavaScript, Laravel, Flutter, dan Firebase.<br><br>Saat ini saya juga sedang mendalami Python, Pandas, dan Machine Learning, dan sudah menyelesaikan beberapa kursus di Kaggle. Di luar kuliah, saya aktif di BEM Fasilkom Unsri, Departemen Relasi bagian Internal, yang melatih saya bekerja dalam tim dan berkomunikasi dengan baik. Saya terbuka untuk belajar hal baru dan berkolaborasi dalam project yang menarik.
